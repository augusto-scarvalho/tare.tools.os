# ADR-OS-SPECGRAPH-001

The operator authorized carrying out the consolidated SpecGraph plan. This decision records the intended composition without changing the sovereignty of Work, sources or execution, and without claiming a tripartite deliberation.

The OS reuses the existing lifecycle/doctor; SpecGraph provides a read-only service; the Library provides catalog and curation; the Backlog remains the authority over Work; the Kernel adapts events and policy. There will be no other orchestration in SpecGraph and no reactivation of the frozen harness.

Hooks load context only when the event/task and the coverage make it useful. Repeated information returns silence; a configuration/source error is summarized once and is diagnosable. A denial without a capable substitute and recovery loops are product failures.

The synchronous handler does no network/LLM/scan work; post-edit schedules a delta. The normal doctor reads metadata; deep/repair are separate actions. Effectiveness is a correct task per total cost, including agents/retries, not a count of hooks or denials.

Acceptance is in the [operational contract](../specs/SPEC-OS-SPECGRAPH-HOOKS-001.md). The implementation will be qualified per host and real event; no runtime change is declared delivered by this ADR.
